##Practical – 8 : GraphX
Step 1: Open Command Prompt and run: spark-shell
Run the following cmmnds one after another 

Step 2 — Import GraphX libraries :
import org.apache.spark._
import org.apache.spark.rdd.RDD
import org.apache.spark.graphx._

Step 3 — Create graph vertices
val vertices = Array((1L, "A"), (2L, "B"), (3L, "C"))
val vRDD = sc.parallelize(vertices)
vRDD.take(1)
vRDD.take(2)

Step 4 — Create graph edges
> val edges = Array(
  Edge(1L, 2L, 1800),
  Edge(2L, 3L, 800),
  Edge(3L, 1L, 1400)
)
> val eRDD = sc.parallelize(edges)
> eRDD.take(2)

Step 5 — Create the Graph
val nowhere = "nowhere"
val graph = Graph(vRDD, eRDD, nowhere)

Step 6 — Display all vertices
graph.vertices.collect.foreach(println)

Step 7 — Display all edges
graph.edges.collect.foreach(println)

Step 8 — Count vertices and edges
val numairports = graph.numVertices
val numroutes = graph.numEdges
println(numairports)
println(numroutes)

Step 9 — Filter edges by property
graph.edges.filter { case Edge(src, dst, prop) => prop > 1000 }.collect.foreach(println)

Step 10 — Display graph triplets
graph.triplets.take(3).foreach(println)

Step 11 — Calculate in-degrees
val i = graph.inDegrees
i.collect.foreach(println)

##Practical-4 : 
Step 1: Install Hadoop
Click https://repo.huaweicloud.com/apache/hadoop/common/hadoop-3.4.3/hadoop-3.4.3.tar.gz

Step 2: Extract Folder 
Cut the Folder inside hadoop-3.4.3 and paste that in C drive
Rename the hadoop-3.4.3 folder name to hadoop

Step 3: Inside hadoop folder create another folder name – data
Inside that data folder create two more folders name – datanode and  namenode

Step 4: Go in Environment Variable
Under System variables, click New
Enter these values:
Variable name - HADOOP_HOME
Variable value - C:\hadoop
Click ok 

Step 5: Under System variables, select Path. Click Edit.
Add the Hadoop bin path, Click New and enter:  C:\hadoop\bin
Click New again and enter: C:\hadoop\sbin
Click OK ok ok

Step 6: Open new cmd and run:
echo %HADOOP_HOME%
hadoop version

Step 7: In the Hadoop directory, browse to etc/hadoop/ and open core-site.xml in Notepad.
Replace its existing contents with the following configuration:
<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<configuration>
    <property>
        <name>fs.defaultFS</name>
        <value>hdfs://localhost:9000</value>
    </property>
</configuration>
Save the file

Step 8: Open: C:\hadoop\etc\hadoop
Find hdfs-site.xml.
Open it in Notepad or VS Code.
Replace its contents with this configuration:
<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<configuration>
    <property>
        <name>dfs.replication</name>
        <value>1</value>
    </property>

    <property>
        <name>dfs.namenode.name.dir</name>
        <value>file:///C:/hadoop/data/namenode</value>
    </property>

    <property>
        <name>dfs.datanode.data.dir</name>
        <value>file:///C:/hadoop/data/datanode</value>
    </property>
</configuration>
Save the file

Step 9 : Do the same for mapred-site.xml & yarn-site.xml.

mapred-site.xml 
<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<configuration>
    <property>
        <name>mapreduce.framework.name</name>
        <value>yarn</value>
    </property>
</configuration>

yarn-site.xml 

<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<configuration>
    <property>
        <name>yarn.nodemanager.aux-services</name>
        <value>mapreduce_shuffle</value>
    </property>

    <property>
        <name>yarn.nodemanager.aux-services.mapreduce_shuffle.class</name>
        <value>org.apache.hadoop.mapred.ShuffleHandler</value>
    </property>
</configuration>

Step 10:  Go to the sbin folder in the hadoop directory. Open cmd there, and write the command:
start-dfs.cmd and in same 
start-yarn.cmd
